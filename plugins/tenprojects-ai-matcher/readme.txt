AI-powered real estate matching engine for 10Projects.com — scoring, recommendations, lead routing, and conversational assessment.

== Description ==

10Projects AI Matcher powers the core functionality of 10Projects.com:

* **20-Category Scoring Engine** — Deterministic Fit Score calculation across budget, location, developer reputation, and 17 more parameters.
* **AI Assessment Chat** — Conversational requirement gathering with Claude/OpenAI/Gemini.
* **Smart Recommendations** — Ranked top-10 projects per customer with explanations.
* **Lead Routing** — Automated lead assignment to channel partners based on location, budget, and capacity.
* **Custom Post Types** — Projects, Developers, Locations, Guides, Reviews, Infrastructure, Market Reports.
* **17 Custom Database Tables** — Customers, sessions, scores, leads, partners, analytics, and more.

== Installation ==

1. Upload to `/wp-content/plugins/tenprojects-ai-matcher/`
2. Activate through the Plugins menu
3. Configure API keys in 10Projects > Settings
